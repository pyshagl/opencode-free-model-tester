# OpenCode Free Model Tester

[English](README.md) | [Русский](README.ru.md)

**Кроссплатформенный тестер условно-бесплатных моделей, доступных через OpenCode.** Одна кодовая база для Windows, macOS и Linux, короткая проверка ответа и отчёты CSV/JSON. Использует уже подключённые к OpenCode провайдеры — вводить API-ключи в программу не нужно.

> **Безопасность:** по умолчанию тестер **только показывает список**. Отправка запросов требует `--run` и подтверждения `YES`. Пометка `Free` в названии **не гарантирует**, что модель будет бесплатной именно для вашего аккаунта. До тестирования проверьте условия тарифа и биллинга.

## Возможности

- Получает модели из `opencode models`, а не парсит сторонние сайты.
- Автоматически отбирает `opencode/*-free`, модели OpenRouter с `:free` и `openrouter/openrouter/free`. Остальные добавляются только вручную.
- Последовательно отправляет короткий тестовый запрос с ограничением времени, без предполагаемого использования инструментов.
- Различает `OK`, `REPLY_UNVERIFIED`, `QUOTA`, `AUTH`, `BILLING`, `REGION`, `MODEL_UNAVAILABLE`, `TIMEOUT`, `MODEL_MISMATCH` и другие состояния.
- Сохраняет отчёты CSV и JSON в `reports/`; папка исключена из Git.
- Использует временную рабочую папку, пытается отключить плагины и запрещает инструменты в процессе теста. Глобальные настройки OpenCode не меняет.

## Быстрый старт

**Требуется:** Windows 10/11, macOS или Linux; Node.js **20+**; установленный OpenCode CLI и ваши подключения провайдеров. Наличие только OpenCode Desktop не означает, что команда `opencode` доступна в терминале.

1. Установите [Node.js](https://nodejs.org/) и [OpenCode CLI](https://opencode.ai/docs/cli/commands). Проверьте `node --version` и `opencode models`.
2. Скачайте репозиторий: GitHub → **Code → Download ZIP**, затем распакуйте.
3. Посмотрите список моделей **без запросов и расходования квот**:

   ```sh
   node src/cli.mjs
   ```

4. Протестируйте первые пять моделей, подтвердив `YES`:

   ```sh
   node src/cli.mjs --run --limit=5
   ```

5. Посмотрите результаты в папке `reports/`.

**Запуск двойным щелчком** после установки зависимостей: Windows — `launchers/windows/*.cmd`; macOS — `launchers/macos/*.command`; Linux — `launchers/linux/*.sh`. Для macOS/Linux иногда требуется `chmod +x`.

## Примеры

```sh
node src/cli.mjs --help
node src/cli.mjs --run --only=openrouter/openrouter/free
node src/cli.mjs --run --exclude=opencode,teamorouter,orcarouter --limit=10
node src/cli.mjs --run --timeout=120 --output=./my-reports
```

Если у модели есть бесплатный тариф, но нет пометки `free` в ID (например, Gemini Flash-Lite), добавьте точный ID в [`config/approved-models.json`](config/approved-models.json) **после проверки своего тарифного уровня**. Это ручное разрешение, а не автоматическая проверка цен.

## Статусы

| Статус | Значение |
| --- | --- |
| `OK` | Получен ожидаемый ответ, и метаданные подтвердили **именно запрошенную модель**. |
| `REPLY_UNVERIFIED` | Ответ есть, но OpenCode не передал достаточно данных, чтобы исключить переключение плагином. |
| `QUOTA` | Исчерпана квота или ограничена частота запросов. |
| `REGION`, `AUTH`, `BILLING` | Ограничение региона, ошибка ключа или недостаточный баланс/биллинг. |
| `MODEL_UNAVAILABLE`, `TIMEOUT` | Модель недоступна или превышено время ожидания. |
| `MODEL_MISMATCH` | По метаданным ответила не та модель, что запрашивалась. |
| `REPLIED_OTHER`, `ERROR`, `NO_REPLY` | Другие исходы — смотрите безопасно сокращённую информацию об ошибке. |

Один ответ **не доказывает** качество кода, поддержку инструментов, стабильность или бесплатность в будущем. У нескольких моделей OpenRouter может быть общий лимит аккаунта.

## Проверка проекта

```sh
npm test
```

Тесты полностью локальные, используют имитацию OpenCode CLI и не требуют API-ключей. CI запускает их на Windows, macOS и Linux. Запросы к настоящим моделям в CI не отправляются.

## Ограничения

Это **независимая утилита сообщества**, не официальный инструмент OpenCode и не плагин маршрутизации. Она не объединяет квоты, не создаёт аккаунты и не меняет биллинг. Каталог CLI может содержать модели, выключенные в Desktop.
