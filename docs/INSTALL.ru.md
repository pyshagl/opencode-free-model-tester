# Установка и использование — русский

[English](INSTALL.en.md) · [README](../README.ru.md)

## Требования

- Windows 10/11 (x64 или ARM64 с совместимыми Node/OpenCode), macOS или Linux.
- Node.js 20 или новее: [nodejs.org](https://nodejs.org/).
- Рабочая консольная версия OpenCode CLI: [официальная инструкция](https://opencode.ai/docs/cli/commands). Одно лишь приложение Desktop не обязательно устанавливает команду `opencode`.
- Хотя бы один провайдер подключён в OpenCode. Авторизацию выполняйте в самом OpenCode, **не вставляйте ключи в тестер**.

Проверьте в терминале:

```sh
node --version
opencode --version
opencode models
```

Если команда `opencode` не найдена, установите **официальный OpenCode CLI** по актуальной инструкции. Один из вариантов — `npm install -g @opencode/cli`. Некоторые версии npm предупреждают о заблокированном скрипте postinstall: в таком случае прежде всего проверьте работоспособность команды `opencode models`.

## Windows

1. На GitHub нажмите **Code → Download ZIP** и распакуйте архив (не запускайте файлы прямо из ZIP).
2. Установите Node.js и OpenCode CLI. В PowerShell выполните три команды проверки выше.
3. Откройте двойным щелчком `launchers\windows\01-List-models.cmd` — список без API-запросов.
4. Откройте `launchers\windows\02-Test-first-5.cmd`, подтвердите `YES`: проверятся пять кандидатов.
5. Отчёты лежат в `reports\`. Для всех кандидатов есть `03-Test-all.cmd`, но учитывайте общий лимит провайдера.

В Windows Node запускает `opencode.exe` или npm-обёртку `.cmd`. Если команда не найдена, добавьте CLI в PATH либо задайте переменную `OPENCODE_BIN` с полным путём к исполняемому файлу.

## macOS

1. Распакуйте проект, установите Node.js и OpenCode CLI, убедитесь, что `opencode models` работает.
2. В Терминале из папки проекта выполните `node src/cli.mjs` (просмотр), затем `node src/cli.mjs --run --limit=5` (проверка).
3. Либо выполните `chmod +x launchers/macos/*.command`, после чего можно открыть `.command` через Finder/Terminal. macOS может запросить разрешение на запуск скачанного скрипта — сначала ознакомьтесь с его содержимым.

## Linux

1. Установите Node.js 20+ и OpenCode CLI способом, подходящим для дистрибутива.
2. В распакованной папке запустите `node src/cli.mjs` или `node src/cli.mjs --run --limit=5`.
3. При желании: `chmod +x launchers/linux/*.sh`, затем выберите сценарий запуска.

## Параметры

```text
--run               Отправлять реальные запросы (попросит ввести YES)
--yes               Явно пропустить подтверждение для автоматизации
--only=id1,id2      Проверять только конкретные ID из разрешённого набора
--exclude=p1,p2     Исключить провайдеров
--limit=N           Максимум N моделей (1..200, по умолчанию 20)
--timeout=N         Тайм-аут на модель (10..300 секунд, по умолчанию 90)
--output=DIR        Папка отчётов
--help              Справка
```

## Ручное разрешение моделей

По умолчанию выбираются только `opencode/*-free`, модели OpenRouter с `:free` и `openrouter/openrouter/free`. Это **не гарантия цены $0**. Остальные добавляются вручную в `config/approved-models.json`:

```json
{ "models": ["google/gemini-3.5-flash-lite"] }
```

Это пример, а не подтверждение бесплатного доступа каждому пользователю. Прежде чем использовать модель, проверьте свой тариф Google API и наличие платного биллинга. Сам тестер настройки не меняет.

## Если что-то не работает

- **Нет `node`:** установите Node.js 20+ и перезапустите терминал.
- **Нет `opencode`:** нужна именно консольная версия CLI, не только Desktop.
- **Список пуст:** проверьте `opencode models`, подключённые провайдеры и список разрешённых ID. Список CLI может отличаться от включённых в Desktop моделей.
- **`QUOTA`/`BILLING`:** закончились лимиты или провайдер требует оплату.
- **`REPLY_UNVERIFIED`:** нет подтверждения, какая модель реально ответила. Не считайте это успешной проверкой: мог вмешаться fallback-плагин.
- **Ошибки инструментов:** тестер пытается запретить инструменты для дочернего процесса. Нестандартные плагины могут игнорировать переопределение; не тестируйте на папке с конфиденциальным кодом.
- **Блокировка скрипта Windows:** проверьте содержимое `.cmd`, не отключайте системную защиту целиком.

Тестер не устанавливает зависимости, не обновляет OpenCode, не получает API-ключи и не проверяет фактические списания денег.
