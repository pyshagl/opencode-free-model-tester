# Участие в разработке

[English](CONTRIBUTING.en.md)

Приветствуются исправления ошибок, улучшения совместимости с OpenCode CLI, документации и тестов. Это независимый проект сообщества, не официальный инструмент OpenCode.

## Перед отправкой pull request

1. Создайте отдельную ветку и опишите изменения для пользователя.
2. Запустите `npm test` (Node.js 20+). Автоматические тесты **не должны** обращаться к реальным API или требовать ключи.
3. Добавьте автономные фикстуры для новых ответов и ошибок. Не добавляйте реальные журналы аккаунтов без удаления приватных данных.
4. Не включайте модели с потенциальной оплатой автоматически и не обещайте вечный бесплатный доступ.
5. Если меняется поведение, обновите документацию на русском и английском.

## Принципы кода

По возможности используйте стандартную библиотеку Node.js. Чистые функции размещайте в `src/core.mjs`, взаимодействие с процессом OpenCode — в `src/cli.mjs`. Сохраняйте режим предпросмотра по умолчанию и явное подтверждение API-запросов. Не логируйте секреты и полное окружение. Не добавляйте скрытый мониторинг и изменения пользовательских проектов.

## Сообщение об ошибке

Укажите ОС, версии Node.js и OpenCode CLI, шаги воспроизведения и **обезличенный** вывод. Не публикуйте API-ключи. Для проверки желательно использовать тестовый CLI из `tests/fixtures`.
