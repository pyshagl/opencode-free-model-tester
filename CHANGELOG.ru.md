# История изменений

[English](CHANGELOG.md)

## 0.1.0 — 10 ноября 2026 года

Первый кроссплатформенный выпуск.

- Единый движок на Node.js для Windows, macOS и Linux.
- Безопасный предпросмотр по умолчанию и последовательные API-тесты по подтверждению.
- Поиск моделей с явной маркировкой Free и пользовательский список разрешений.
- Классификация ошибок и осторожная проверка фактически ответившей модели.
- Отчёты CSV/JSON в UTF-8, частичная маскировка секретов, защита CSV-значений от формул.
- Запускатели и инструкции для трёх ОС.
- Автономные модульные/интеграционные тесты и проверки GitHub Actions.

### Известные ограничения

- Метка Free не гарантирует бесплатный доступ для всех аккаунтов.
- Формат JSON-событий и поведение плагинов могут различаться между выпусками OpenCode.
- Один успешный короткий ответ не проверяет качество программирования и работу инструментов.
